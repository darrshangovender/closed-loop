# What the proof says (SYNTHETIC)

Generated by `benchmarks/run.py` from `benchmarks/results.json`. The numbers are counts of a finite abstract model, found by exhaustive enumeration, and the conformance figures are measured on sampled traces of the simulated plant.

## Statement

Under A_iso, A_exec, A_phys, A_map and C1, if every command issued to the components that have a game in this run (crusher, pumps, conveyor) is in the shield's allowed set, then no state that violates P1 to P5 is reachable in the abstract models, from their initial states, for any environment behaviour the models allow. It is checked by explicit enumeration of the reachable product of game state, hidden health bin and perception set. It is a statement about the abstract models. It is not a statement about the F1 or F2 simulators.

## Assumptions the statement needs

| ID | Assumption | How it is tested |
|---|---|---|
| A_iso | isolation holds once proven (no energy release while isolated) | not testable here; stated |
| A_exec | STOP and EXIT are executed; every other command may be refused | plant code and unit test; conformance trace check |
| A_phys | a health bin rises by at most one per tick; an uncontrolled failure occurs only from the top bin while running | measured on sampled traces (below) |
| A_dec | components interact only through the properties of the pump pair, so the game decomposes | argued; a unit test on the atoms of the specification |
| C1 | the perception set holds the true health bin at every tick | monitored by an e-process whose unit is the life (below) |
| A_map | the abstraction map and the predicates are right | conformance test; an independent reimplementation of the relation |

C1 holds at every tick, which is an event of a whole life. The set the shield uses by default is the per-life 95% band (`life95`); a per-step 99% set is an ablation and does not deliver C1 as stated. The sequential unit of the monitor modes that read labels (`opt`, `pess` and `inf`) is the life, and their test assumes the lives are independent given the past (a conditional-mean assumption); checkpoints within a life are dependent, so a per-checkpoint test would not satisfy the condition Ville's inequality needs. The unit of mode `proxy` is the day (the miss indicator of a one-day-ahead band), it needs no label and it is not a test of C1; its false-alarm rate is measured on the unshifted episodes in `RESULTS.md`, and the test does not bound it.

## What the statement does not cover

- Violations the abstraction cannot express: a mistaken zero-energy test, an unmodelled hazard class, two simultaneous entries.
- Anything while C1 fails, except under the fallback: when the monitor fires, the sets become the whole range and C1 holds by construction, and the statement then stands conditional on the other assumptions.
- Concrete-plant behaviour with no abstract counterpart (the measured gap above), and the 15-minute quantisation.
- A wrong specification: the specification is what this repository wrote, not what a regulator wrote. The permit suspension on an emergency alarm (clause 6.2 of the permit document) is a clause the specification does not cover.
- The game is stricter than the properties: some commands are violations in the game that have no formula among P1 to P6, so the shield refuses more than the properties require.
- The renewal of a component on completing a job is an environment choice in the models (a wrong-mode job completes and renews nothing).
- The pump availability definition: a locked-out pump is not available.
- A confined-space task of N quarters becomes N cycles of test, enter, exit; the throughput this costs is measured against the interlock in `RESULTS.md`.
